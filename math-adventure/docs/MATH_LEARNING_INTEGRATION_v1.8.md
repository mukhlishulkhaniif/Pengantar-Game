# Math-Adventure v1.8 — Integrasi Pembelajaran

## Perubahan
- Setiap wave menampilkan banner terlebih dahulu, lalu membuka tantangan matematika otomatis.
- Menjawab benar memberi energi dan skor; menjawab salah tetap memberi +10 energi serta menampilkan jawaban benar.
- Pemain dapat melewati soal tanpa bonus, lalu melanjutkan permainan.
- Tombol energi tetap membuka soal bonus kapan saja ketika permainan tidak sedang dijeda.
- Setelah jawaban dipilih, tombol jawaban dikunci dan panel menampilkan hasil selama 1,15 detik sebelum permainan berlanjut.
- Rentang soal bertahap: Mudah 0–10, Sedang 10–30, Sulit 20–50 (nilai operand); pengurangan tidak menghasilkan bilangan negatif.
- Histori jawaban tetap dicatat untuk ringkasan akhir dan pembahasan soal.

## Alur pemain
1. Banner wave tampil di tengah.
2. Setelah banner hilang, tantangan wave muncul.
3. Jawaban benar: bonus energi penuh dan skor.
4. Jawaban salah: jawaban benar ditampilkan dan pemain mendapat +10 energi.
5. Pemain bisa melewati soal; tanpa bonus tambahan.

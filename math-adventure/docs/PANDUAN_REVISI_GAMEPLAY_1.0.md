# Panduan menerapkan revisi gameplay v1.0

1. Tutup proyek Math-Adventure di Godot.
2. Buat commit di GitHub Desktop sebelum mengganti file, atau pastikan perubahan lokal yang belum dicommit sudah aman.
3. Ekstrak ZIP ini ke folder `D:\GODOT\Pengantar-Game\` dan pilih opsi untuk menggabungkan folder serta menimpa file yang sama.
4. Buka kembali `math-adventure/project.godot` di Godot 4.7.2.
5. Tunggu proses pemindaian/import selesai. Periksa tab Debugger untuk parser error.
6. Jalankan game dari menu utama dan uji grid 5 x 9, drag-and-drop, HP Guardian, serangan monster, jangkauan Addy, serta tiga wave.
7. Jika pengujian desktop berjalan baik, ekspor APK Android baru dan uji di HP.

ZIP ini menyertakan seluruh sumber proyek dan dokumentasi, tetapi sengaja tidak menyertakan folder cache `.godot`. Godot akan membuat cache tersebut kembali secara otomatis. APK lama tidak diubah.

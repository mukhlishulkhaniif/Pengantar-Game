# Math-Adventure v2.1 — PvZ Pacing & Random Lanes

## Perubahan
- Musuh dapat muncul acak dari kelima baris sejak wave pertama.
- Baris yang sama tidak dipilih dua kali berturut-turut, agar acak tetap terasa adil.
- Jumlah musuh per wave: 4, 5, lalu 6.
- Interval spawn: 6,5 detik di wave 1; 6,0 detik di wave 2; 5,5 detik di wave 3.
- Kecepatan musuh reguler: 9,5; Minus Monster: 8; Calculator Bug: 12.
- Jeda antargelombang menjadi 3,2 detik.
- Damage Addy Cannon diturunkan menjadi 13; Multiply Dragon menjadi 17; Number Knight menjadi 17.
- Sistem soal dan hadiah energi v2.0 tetap dipertahankan.

## Pengujian manual
1. Pastikan monster muncul dari berbagai baris pada setiap wave.
2. Pastikan monster tidak selalu muncul dari baris tengah.
3. Perhatikan jarak antarkemunculan dan waktu tempuh monster.
4. Pastikan 4, 5, dan 6 monster muncul pada wave 1, 2, dan 3.
5. Uji apakah energi dari soal masih cukup untuk menyiapkan Guardian.

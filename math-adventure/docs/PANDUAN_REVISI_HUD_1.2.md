# Panduan memasang revisi HUD v1.2

1. Commit perubahan saat ini melalui GitHub Desktop.
2. Ekstrak paket revisi ke folder `D:\GODOT\Pengantar-Game\` dan gabungkan folder `math-adventure` dengan folder yang sudah ada.
3. Timpa file yang sama jika diminta.
4. Buka `math-adventure/project.godot` di Godot 4.7.2.
5. Jalankan proyek dan periksa tab Debugger.
6. Uji HUD landscape, tombol pause/home, dan banner transisi wave.
7. Ekspor APK baru hanya setelah pengujian lolos.

Jangan hapus repository Git atau folder proyek asli. Jika hasil revisi bermasalah, gunakan GitHub Desktop untuk membandingkan atau memulihkan file.

# Adventure Math

## Product Requirements Document (PRD)

## 1. Product Overview

Adventure Math adalah game edukasi matematika berbasis Educational Tower
Defense untuk perangkat mobile. Pemain mempertahankan dunia Numeria dari
serangan Math Error dengan menggunakan Math Energy yang diperoleh
melalui penyelesaian soal matematika.

## 2. Product Goal

Game memiliki tujuan: - Membuat pembelajaran matematika terasa seperti
bermain game. - Melatih kemampuan berhitung anak SD. - Menggabungkan
strategi dan edukasi. - Memberikan pengalaman bermain yang mudah
dipahami melalui perangkat mobile.

## 3. Target User

Primary User: - Anak usia SD (kelas 1-6). - Pengguna Android/iOS.

Secondary User: - Orang tua. - Guru.

## 4. Core Gameplay

Flow:

Buka Game → Pilih Dunia → Memulai Wave → Menjawab Soal → Mendapat Math
Energy → Memanggil Guardian → Mengalahkan Math Error → Mendapat Reward →
Upgrade Guardian

## 5. Battle System

Jenis Battle: - Tower Defense. - Multiple Lane Defense. - Wave Based
Combat.

Player: - Math Energy. - Guardian Collection. - Progress Level.

Enemy: - HP. - Attack. - Speed. - Ability.

## 6. Math Energy System

Math Energy adalah resource utama untuk memanggil Guardian.

Energi diperoleh melalui: - Jawaban matematika benar. - Combo jawaban. -
Reward level.

## 7. MVP

Versi pertama: - 1 dunia. - 3 Math Guardian. - 2 jenis Math Error. -
Materi penjumlahan dan pengurangan. - Sistem wave sederhana.

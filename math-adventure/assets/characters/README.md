# Karakter PNG

File PNG transparan yang dibaca otomatis:
- `plusy.png`
- `addy_cannon.png`
- `shield_cube.png`
- `multiply_dragon.png`
- `fraction_fairy.png`
- `number_knight.png`
- `error_blob.png`
- `minus_monster.png`
- `calculator_bug.png`

Spesifikasi awal: PNG RGBA transparan, sekitar 512 × 512 px per karakter, seluruh tubuh terlihat, ada ruang kosong di sekeliling siluet, menghadap ke kanan jika karakter menyerang. Gunakan outline tinta hitam yang konsisten, bentuk ekspresif dan lentur, palet krem, hitam, hijau tua, serta warna vintage. Karakter harus orisinal.

Versi saat ini memuat satu pose statis per file. Animasi sprite sheet dapat ditambahkan setelah desain dasar disetujui.

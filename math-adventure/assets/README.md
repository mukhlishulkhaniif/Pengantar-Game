# Aset Math-Adventure

Folder ini menampung aset orisinal untuk gaya kartun tinta klasik era 1930-an. Loader di `scripts/presentation/arena_view.gd` sudah mendukung file PNG opsional. Jika PNG belum ada, game tetap memakai gambar fallback yang digambar melalui kode.

Jangan gunakan karakter, logo, atau gambar yang disalin dari Cuphead atau Plants vs. Zombies. Kita hanya mengambil inspirasi dari teknik ilustrasi dan animasi vintage, dengan desain orisinal untuk Math-Adventure.

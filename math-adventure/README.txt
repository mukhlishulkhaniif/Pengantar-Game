MATH-ADVENTURE DISPLAY FIX (Godot 4.7.2)

This patch contains only project.godot.

INSTALL:
1. Stop the running game and close the Godot editor.
2. Make a backup copy of the existing file:
   D:\GODOT\Pengantar-Game\math-adventure\project.godot
3. Extract this ZIP into:
   D:\GODOT\Pengantar-Game\math-adventure
4. When Windows asks whether to replace project.godot, choose Replace.
5. Reopen Math-Adventure in Godot and press F5.

The configuration sets the logical viewport to 1280x720 and opens the game maximized. It expects the main scene at res://scenes/main_menu.tscn.
If that scene file is missing, do not continue; check the scenes folder first.

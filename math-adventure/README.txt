MATH-ADVENTURE MVP v1.3 — ENAM GUARDIAN AKTIF
Godot 4.7.2 | Android mobile landscape | Grid 5 x 9

PAKET INI
- Proyek lengkap untuk mengganti file sumber yang terkait HUD dan gameplay.
- Enam Guardian yang dapat dipilih dan ditempatkan.
- Sistem HP, serangan, area damage, penyembuhan, dan serangan balik.
- Ilustrasi prosedural untuk Dragon, Fairy, dan Number Knight; PNG bisa ditambahkan pada tahap aset.
- Dokumentasi perubahan di docs/CHANGELOG_MVP_1.3_SIX_GUARDIANS.md.

CARA MEMASANG
1. Di GitHub Desktop, commit perubahan lokal terlebih dahulu.
2. Tutup game dan Godot Editor.
3. Ekstrak ZIP ini ke D:\GODOT\Pengantar-Game\ dan gabungkan folder math-adventure; izinkan file yang sama ditimpa.
4. Buka D:\GODOT\Pengantar-Game\math-adventure\project.godot di Godot 4.7.2.
5. Tunggu pemindaian/import selesai. Jalankan proyek dengan F6/F5 sesuai scene aktif.
6. Periksa tab Debugger sebelum mengekspor APK baru.
7. Setelah pengujian battle berhasil, ekspor APK dan uji kembali di HP.

PENTING
- Paket ini tidak menyertakan cache .godot agar ringan; Godot akan membuat cache kembali.
- APK lama tidak diubah.
- Kode telah diperiksa secara statis, tetapi belum dijalankan langsung di Godot pada lingkungan pembuat ZIP. Uji lokal sebelum mengganti APK yang sudah berfungsi.
